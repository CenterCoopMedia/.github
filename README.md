# .github

Organization-wide GitHub configuration and profile for the **Center for Cooperative Media**.

## What's in This Repository

| File / Folder | Purpose |
|---|---|
| `profile/README.md` | Organization profile displayed on [github.com/CenterCoopMedia](https://github.com/CenterCoopMedia) |
| `CONTRIBUTING.md` | Default contributing guidelines for all org repos |
| `CODE_OF_CONDUCT.md` | Contributor Covenant code of conduct |
| `ISSUE_TEMPLATE/` | Bug report and feature request issue templates |
| `PULL_REQUEST_TEMPLATE.md` | Default pull request template |
| `FUNDING.yml` | Sponsor/funding button configuration |

## How It Works

GitHub automatically applies these files as defaults across all repositories in the **CenterCoopMedia** organization. Individual repos can override any of these by adding their own versions.

## About the Center for Cooperative Media

An initiative of the College of Communication and Media at Montclair State University. Our mission is to grow and strengthen local and collaborative journalism in New Jersey and beyond.

Learn more at [centerforcooperativemedia.org](https://www.centerforcooperativemedia.org).
