# Contributing to Center for Cooperative Media Projects

Thank you for your interest in contributing! This guide applies to all repositories in the [CenterCoopMedia](https://github.com/CenterCoopMedia) organization.

## How to Contribute

1. **Fork** the repository you want to contribute to.
2. **Create a branch** for your change (`git checkout -b my-change`).
3. **Make your changes** and commit with a clear message describing what you did and why.
4. **Open a pull request** against the `main` branch.

## Reporting Issues

- Use the repository's issue tracker.
- Include steps to reproduce the problem, expected behavior, and actual behavior.
- Screenshots or logs are always helpful.

## Code Style

- Follow the conventions already present in the project.
- Keep pull requests focused — one logical change per PR.

## Code of Conduct

All contributors are expected to follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## Questions?

If you're unsure about anything, open an issue and ask. We're happy to help.
